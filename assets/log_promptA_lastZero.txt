⏺ I added lastZero.test.js. The suite passes (exit code 0) with 8 passing tests
  and 1 test marked todo. That last one fails because lastZero has a bug.

  The bug: the loop runs forward from index 0 and stops at the first zero it
  finds, so it returns the first zero's index, not the last. For example,
  lastZero([0, 1, 0]) returns 0 instead of 2. This is the // test: x = [0, 1, 
  0]; Expected = 2 case in hw1.js. The code only gives the right answer when the
  array has zero or one zeros.

  Tests in lastZero.test.js:
  - Throws TypeError for anything that isn't an array: null, undefined, a
    string, a number, or an array-like object
  - Returns -1 for an empty array
  - Returns -1 when the array has no zero
  - Uses strict equality, so '0', false, null and '' don't count as zero
  - Counts -0 as zero
  - Finds a single zero at the start, middle or end
  - Marked todo: returns the last index when there are several zeros (this is
    the one that fails)
