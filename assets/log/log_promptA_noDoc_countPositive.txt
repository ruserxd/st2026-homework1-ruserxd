  Zero is counted as positive. The check is x[i] >= 0, so countPositive([-4, 2, 
  0, 2]) returns 3, not 2, and 0 and -0 are both counted. Zero isn't positive,
  so this looks like the fault in this function. Because you asked for passing
  tests, they expect the current behavior: the test counts 0 (current behavior: 
  condition is x[i] >= 0) locks in what is probably a bug. A test with only the
  code to go on can't tell a bug from intended behavior, which may be useful for
  your promptA vs. promptB comparison. If the function should count strictly
  positive numbers, change the condition to x[i] > 0 and flip those two
  assertions.
