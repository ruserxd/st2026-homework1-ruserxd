  What the tests check:
  - Returns -1 when there's no 0: empty arrays, arrays with no zeros, NaN, empty
    slots in a sparse array, and values that only loosely equal 0 ('0', false,
    null, '', []).
  - Returns the last index of 0: a 0 at the start, middle or end; several zeros;
    all zeros; mixed element types; a 0 after empty slots; a 100,000-element
    array; and that the input array isn't changed.
  - Throws TypeError: for undefined, null, numbers, strings (including '0'),
    booleans, plain objects, array-like objects, functions, a Set, and calling
    it with no argument.

  Two choices where the spec is unclear. Change these tests if you read it
  differently:
  - Strict equality: I assumed "0" means the number 0, so '0' and false don't
    count.
  - -0: I treated -0 as 0, which is what === does.

  To run: the tests load ./lastZero.js, which can export the function directly
  or as { lastZero }. Then run:
